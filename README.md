# Rewa Sharma — Personal Profile Website

A responsive, beginner-friendly portfolio for **AI Web Development — Task 1**. It uses only HTML, CSS, and JavaScript.

## Run locally

1. Open this folder in VS Code (or another editor).
2. Open `index.html` in a browser, or use the VS Code **Live Server** extension.
3. No installation or build step is required.

## Files

- `index.html` — semantic page structure and content
- `style.css` — responsive visual design and animations
- `script.js` — navigation menu, scroll state, reveal effects, and demo form feedback

The form is intentionally a frontend-only demonstration and does not submit information.
